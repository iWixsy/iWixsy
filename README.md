- 🌐 Ağ sistemleri ve altyapı teknolojilerine odaklanıyorum.
- 🐧 Linux tabanlı sunucuların yönetimiyle ilgileniyorum.
- ⚡ Tekrarlayan işleri Python, Bash ve Docker ile otomatikleştirmeyi seviyorum.
- 🔒 Ağ güvenliği ve açık kaynak araçlar hakkında kendimi geliştiriyorum.
- 🎯 Hedefim ağ ve sistem mühendisliği alanında uzmanlaşmak.
